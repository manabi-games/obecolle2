# おべんきょコレクション2 v1.3.0 — 遊びやすさ全面立て直し

v1.3.0 は、v1.2.0 を10分程度実際に遊んだ際に露呈した「子どもが5分で離脱する」レベルの操作・導線・問題設計を立て直すリリースです。

目的は機能数を増やすことではありません。6歳児が説明なしでも迷いにくく、押した操作が最後まで完了し、正解した喜びが分かり、次に何をすればよいか理解できる状態にします。

## 1. 建物を押したら、その建物へ自動で入る

v1.2 では建物タップ後、入口座標へのBFS経路が取れない・最終地点が入口判定より少しずれる場合、主人公が建物の近くで止まりました。その後ユーザーが手動で入口へ動かす必要がありました。

v1.3 では `findPathToDoor()` を追加します。

- 正面だけでなく入口周辺の複数の安全な接近地点を探索
- 建物に近い接近地点を優先しつつ、到達可能な最短経路を選択
- 経路を歩き切ったら入口距離の再判定を要求せず、そのまま施設へ入る
- 万一経路生成に失敗しても、建物タップというユーザー意思を優先して施設へ入る

**受入条件: 建物を1回押した後、方向キーを一度も使わず施設へ入れること。**

## 2. 生き物問題を「同じ5匹ループ」から作り直す

v1.2 では魚・恐竜・生き物の各Lvで問題生成indexが毎回0付近から始まり、Lvごとのrecent履歴も独立していました。そのため、レベルが変わっても同じ先頭の5匹前後が繰り返し出る設計になっていました。

v1.3 では以下へ変更します。

- 魚: レベルごとに出題プールをずらし、全体で40種以上を実際に出題対象へ
- 恐竜: レベルごとにキャストをローテーションし、25種以上を出題対象へ
- 生き物: 30種の身近な生き物データを用意し、25種以上を出題対象へ
- 同一Lvの直近問題履歴を10件→20件へ拡大
- 1セッション5問内の重複を禁止
- 「同じ5匹で質問文だけ変える」構造を廃止

生き物系の知識問題は、曖昧な推測問題を減らします。

- 魚: 名前、淡水/海、見た目、安全性の高い基礎知識、ゲーム内釣り場
- 恐竜: 名前、食性、時代、明瞭な外見特徴、図鑑上の体長帯
- 生き物: 名前、主な環境、主な食べ物、代表的な動き、基礎特徴

旧実装のような形状コードだけから「2本足/4本足」を推測する問題は使いません。

## 3. 正解・不正解を一瞬で分かる演出へ

回答後、文章を読まないと結果が分からない状態をやめます。

- 正解: 画面中央に大きな赤い `○`
- 不正解: 画面中央に大きな `×`
- 正解選択肢を明示
- 選んだ誤答も明示
- `せいかい！ / おしい！` を大型表示
- 連続正解時は `2れんぞく！` 等を表示
- 次へボタンを分かりやすくする

**受入条件: 文字を読まなくても0.5秒以内に正誤が視覚的に分かること。**

## 4. 英語に「声をきく」機能を追加

英語の文字だけを見ても、6歳児には発音が分かりません。外部音声ファイルやAPIに依存せず、Chrome/EdgeのWeb Speech APIを利用します。

- 英語問題に `🔊 こえを きく` ボタン
- 何度でも再生可能
- `SpeechSynthesisUtterance`
- `en-US`
- 子どもが聞き取りやすいよう少しゆっくりした速度
- ゲーム内「おと」音量に連動
- 次の問題へ移ると前の読み上げを停止

英語問題には発音用payloadを必須化し、自動テストで欠落を検出します。

## 5. 「しまへ」を常設し、迷子をなくす

v1.2 は画面ごとに戻るボタンを個別実装していたため、`しまへ` がある画面・ない画面が混在していました。

v1.3 ではゲーム中HUDに `🏝 しま` を常設します。また「ひとやすみ」「せってい」からも島へ戻れます。

ミニゲーム途中で押した場合は、誤操作防止の確認を1回だけ出します。釣り・発掘の残り回数は既存セーブに保持し、途中離脱で消失させません。

**受入条件: タイトル/キャラ作成以外のゲーム中は、原則1操作または確認1回で島へ戻れること。**

## 6. タイピングの解放条件を「見える化」＋早期化

v1.2 の `さかなれすきゅー` は基本タイピングLv7到達が条件でしたが、画面には `🔒Lv7` としか表示せず、特殊モードを何度遊んでも基本Lvが上がらないことも説明していませんでした。

v1.3 は以下へ変更します。

- 基本Lv1→2→3…を進めることが成長ルートだと大きく表示
- ロック中のモードに「きほんLvNをクリアでOPEN」と表示
- クリア条件 `5ご・せいかくさ60%以上` を結果画面にも表示
- 解放時に `OPEN！` バナー
- 結果画面に次の基本Lvへのボタン
- 特殊モードをもっと早く遊べるよう解放を前倒し

新しい解放:

- 30びょうちゃれんじ: 基本Lv3到達（基本Lv2クリア）
- さかなれすきゅー: 基本Lv4到達（基本Lv3クリア）
- きょうりゅうからにげろ!: 基本Lv7到達（基本Lv6クリア）
- たいぴんぐばとる: 基本Lv10到達（基本Lv9クリア）

## 7. ランク曲線を60Lv版へ再設計

v1.2 は学校最大180スターなのにRank10条件も180スターで、全60Lvをすべて5/5正解にしないとRank10へ到達できませんでした。

新しいRankしきい値:

`[0, 1, 5, 10, 18, 28, 40, 52, 64, 75]`

Rank10は75スター。3/5で進める子どもでも、途中で4/5・5/5を取ったり好きなLvを遊び直したりする自然なプレイで到達可能な曲線へ変更します。

既存セーブの `manabiRank` は `evaluate()` がランクを下げないため、旧プレイヤーを降格させません。
