# Obecolle2 v1.9.0

- Removed the global three-friend request lock. Each active friend can now keep one request.
- Existing requests are explained as the current request instead of showing a blocking error.
- Island toast notifications move to the upper-right so they do not overlap the walking controls.
- Added Typing Dojo with fixed-repeat 10-word, 30-word, and 60-second personal-best challenges.
- Dojo records are stored in progression.storyFlags, preserving v1 save compatibility.
- New-record voice feedback says "しんきろく！" and recent five results are displayed.
- Typing excavation remains unchanged and is linked to the dojo from the same facility.
