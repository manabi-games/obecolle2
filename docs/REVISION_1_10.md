# Obecolle2 v1.10.0

- Typing Dojo is now a standalone town facility.
- Dojo modes are 10 words, 20 words, and 60 seconds.
- Dojo words are shuffled each run from a larger child-friendly word bank.
- Every dojo run pays coins; new records add a bonus.
- Three achievable record thresholds unlock reward-only wearable items.
- School subject cards are compact instead of filling the entire screen.
- Each core subject now shows all levels on one screen (8/10/12) with no paging.
- The unclear Memories entry is hidden from Collection; legacy memory data remains compatible.
- Global menu/card density was tightened to reduce oversized frames and wasted space.
