# Obecolle2 v1.6 - Vertical Slice

Goal: stop adding systems and make the core loop readable and fun.

- School exposes only Math / Japanese / English. Legacy subject save data is retained.
- English never speaks the correct answer before selection. Each answer has its own speaker button.
- Learning level lists are paged 6 at a time and fit without routine scrolling.
- Typing excavation is a self-contained one-screen 2D excavation board.
- Typing hub makes the current level obvious and pages 6 levels at a time.
- Dinosaur atlas crops are inset to prevent neighboring sprites leaking into cards.
- Friend dialogue is character-specific everyday conversation; typing is no longer every friend's topic.
- Shop clothing and hats use distinct silhouettes instead of the same repeated emoji.
- Key gameplay panels have explicit low-height layouts for 1366x600-class windows.
- Fishing / old excavation / arena remain hidden, not deleted, for save compatibility.
