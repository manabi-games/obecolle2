# Obecolle2 v1.7 - Room Rebuild

Goal: make rooms understandable in one glance and remove dead systems from the visible UX.

- Removed the visible aquarium / dinosaur figure / trophy collection-display editor.
- Existing save data for those collections is preserved for compatibility.
- Own room now exposes only room layout and wardrobe.
- Room layout is a two-step flow: choose one of six locations, then choose one of six furniture cards.
- Removed the dense furniture strip, simultaneous placement map, and clear-all action.
- Clicking furniture in the own room opens that exact location for editing.
- Mansion is now a paged room selector rather than a 3D window hunt.
- Friend rooms are view / talk / gift only; gifts are auto-arranged.
- Friend rooms receive simple individual wall/floor palettes and furniture defaults.
- Gift and wardrobe lists use six cards per page and low-height no-scroll layouts.
- Shop item artwork remains provisional and is intentionally deferred for a later Codex visual pass.
- Typing excavation is unchanged from v1.6.
